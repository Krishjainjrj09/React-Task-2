# 👥 Intern Profile Cards

A modern and responsive React application that displays intern profiles in an attractive card-based layout. The project demonstrates React fundamentals along with search, filtering, and reusable components.

## ✨ Features

- **Profile Cards:** Display intern names, roles, locations, and skills.
- **Profile Avatars:** Generate initials from each intern's name.
- **Search Functionality:** Search interns by name, role, or location.
- **Role Filters:** Filter profiles based on job roles.
- **Dashboard Statistics:** Display total interns, unique roles, and skills.
- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **Interactive UI:** Includes hover effects, badges, and modern styling.

## 🛠️ Technologies Used

- HTML5 and JSX

## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed on your system.
- A code editor such as Visual Studio Code.

### Installation

1. Clone the repository or download the project files.

2. Open the project folder in VS Code.

3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173`.
